title: Customization Inventory

This is a map of the repo paths that ship Ryoku's behavior and where they land
on a machine. The authoritative, file-level map is the in-repo
[`docs/structure.md`](https://github.com/Ryoku-dev/ryoku/blob/main/docs/structure.md);
this page is the overview.

The packages copy the base config to `/usr/share/ryoku/config`, and
`ryoku materialize` lays it into `~/.config`, replacing Ryoku-owned files but
never touching your own overrides. See [Customize](/docs/customize) for the
override files and [Updates](/docs/updates) for how updates apply.

## The desktop: `ryoku/`

| Path | What it holds | Lands in |
| --- | --- | --- |
| `ryoku/wm/` | The window-manager seam: the provider contract, the keybind catalogue, and one provider per compositor. | `ryoku-wm-*` binaries |
| `ryoku/hyprland/` | Hyprland's config as Lua modules, one concern per file. | `~/.config/hypr/` |
| `ryoku/niri/` | niri's config as KDL, one concern per file. | `~/.config/niri/` |
| `ryoku/wayfire/` | The experimental Wayfire config. | `~/.config/wayfire/` |
| `ryoku/shell/` | The shell: the QML UI, the `ryoku-shell` daemon, Ryogami, the `Ryoku.Blobs` plugin, matugen templates and the leaf helper scripts. | `~/.config/quickshell/`, `/usr/bin` |
| `ryoku/hub/` | Ryoku Settings: the QML pages and the `ryoku-hub` backend. | `~/.config/quickshell/hub/`, `/usr/bin/ryoku-hub` |
| `ryoku/ui/` | `Ryoku.Ui`, the shared tokens and primitives. | `/usr/lib/qt6/qml/Ryoku/Ui` |
| `ryoku/cli/` | The `ryoku` command, including `ryoku doctor`. | `/usr/bin/ryoku` |
| `ryoku/apps/` | Native configs for kitty, ghostty, fish, zsh, bash, starship, nvim, yazi, btop, fastfetch, nautilus, wireplumber and more, plus Ryostore and Ryovm. | `~/.config/<app>/` |
| `ryoku/lockscreen/` | The qylock lock screen and the SDDM greeter setup. | the greeter and the lock screen |
| `ryoku/rashin/` | Rashin, the local agent and its dashboard. | `/usr/bin`, `~/.local/share/ryoku/rashin/` |
| `ryoku/assets/` | Brand art, the shipped wallpapers and the rices (Default, NOC). | `/usr/share/ryoku/` |
| `ryoku/i18n/` | The translation catalog and its runtimes. | `/usr/share/ryoku/i18n` |

## The machine: `system/`

| Path | What it holds |
| --- | --- |
| `system/boot/` | The boot chain: Limine, Plymouth, the initramfs setup. |
| `system/hardware/` | Hardware policy and helpers: GPU, power, audio, network. |
| `system/packages/` | The package sets every install draws from. |
| `system/services/`, `system/policy/` | System services and polkit policy. |
| `system/extras/` | The bundle actuator (`ryostore-install`) and its package helpers. |

## The editions and installers

| Path | What it holds |
| --- | --- |
| `installation/` | The installer TUI, the backend, the shared choice catalogue (`installerplan/`) and the Arch and CachyOS ISO profile. |
| `ryoku-shell-installer/` | The script installer for existing Arch, CachyOS, Void and Fedora systems. |
| `void/` | Void's package translations, its runit service translations and its ISO. |
| `fedora/` | Fedora's package translations and RPM specs. |
| `release/` | The `[ryoku]` PKGBUILDs, the repository builder and the release tooling. |

## Files that are yours

Ryoku never overwrites these on an update:

| File | What it is for |
| --- | --- |
| `~/.config/ryoku/user_edits/` | Every change you make in Ryoku Settings, laid back over the shipped config on each update. `ryoku reset` hands a file back. |
| `~/.config/hypr/user.lua`, `~/.config/niri/user.kdl` | Your own window-manager overrides, loaded last. |
| `monitors_user.lua`, `monitors_user.kdl` | Hand-pinned displays. |
| `~/.config/kitty/user.conf`, `~/.config/fish/user.fish` | Per-app overrides. |
| `~/.config/ryoku/plugins.json` | Plugin placement and settings. |

`ryoku owner <path>` tells you which class any config file belongs to and where
your change should go; see [The ryoku command](/docs/cli).
