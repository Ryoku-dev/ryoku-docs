Ryoku keeps its core deliberately small: a terminal, an editor, a browser, a
file manager, and the shell that ties them together. Everything else, a game
launcher, a streaming rig, a full dev stack, is added on demand as a
**bundle**: a curated set of software installed together, so adding a whole
workflow is one click instead of an afternoon of hunting packages and their
drivers.

Bundles install *software*. For the small desktop **widgets** you place on the
wallpaper, see [Plugins](/docs/plugins), a separate system that lives in the
same store.

## Install a bundle

<Steps>
  <Step title="Open Ryostore">
    Open **Ryostore** from the launcher, or press **Browse RyoStore** on the
    Add-ons page of Ryoku Settings. Bundles sit beside lockscreens, rices, bar
    styles and plugins; each one shows what it contains and its live install
    state.
  </Step>
  <Step title="Pick a bundle and install">
    Open a bundle to see its items, then **Install**. Ryostore opens a floating
    terminal so `sudo` has a real prompt, and streams progress as each item
    lands.
  </Step>
  <Step title="Watch it fill in">
    Items report present or absent live, so the bundle updates as it installs.
    Remove it the same way. Installed bundles are also listed on the Add-ons
    page, where you can repair or remove them.
  </Step>
</Steps>

The catalogue lives in the
[`ryostore`](https://github.com/Ryoku-dev/ryostore) repository. Ryostore fetches
and caches it, and the actuator, `ryostore-install`, only ever reads that cache.

## The bundles

| Bundle | What it adds |
| --- | --- |
| Gaming | Launchers, Wine and Proton, performance overlays, controller support and console emulators, plus the matching 32-bit GPU drivers. |
| The Influencer | Recorders, editors, audio and thumbnail tools, and a right-click video toolkit in the file manager. |
| Developer Essentials | Build basics, Git and GitHub CLI, shell search tools, C/C++ build and debug tools, language runtimes, Docker and VS Code. |
| Web Browsers | Firefox, Firefox Developer Edition, Chromium, Brave, LibreWolf and Zen Browser. |
| VPN & Networking | WireGuard, OpenVPN, IPsec/IKEv2, Proton VPN, Mullvad VPN and Cloudflare WARP. |
| Rice Showcase | Terminal toys for showing off a rice: Matrix rain, bonsai, visualizers, system readouts and ASCII banners. |
| Ryotunes | The Ryoku-native music player, with MPRIS and live desktop theming. |
| Ryoku Palette Bridge | Wallpaper colours for Spotify and Vesktop, with optional live theming for Zen. |
| Ryoku for Zed | Zed follows Ryoku's wallpaper palette. |
| MJ Widget Set | 25 desktop widgets, ported from end4's illogical-impulse, with live Ryoku theming. |
| CachyOS Layer | The CachyOS kernel, tuning, sched-ext schedulers, ananicy-cpp and CachyOS Proton. Arch only. |

<Note>
  The **CachyOS Layer** turns an Arch install into CachyOS, kernel included,
  and is also offered as a choice in the installer. Read
  [Kernels](/docs/kernels) for the trade-offs and the rollback path before you
  add it.
</Note>

## What a bundle contains

A bundle is a list of items. You never write or see the routing; the actuator
picks the right path per item.

| Kind | What it is | How it installs |
| --- | --- | --- |
| **package** | A distribution package. | Installed with your edition's package manager. On Arch, a package that is not in the official repositories is built from the AUR. Packages are batched. |
| **script** | A small installer from the catalogue's `installers/`, for tools no repository carries. | Run with `bash`, then detected by a `command -v` check. |
| **plugin** | A shell [plugin](/docs/plugins), such as a desktop widget. | Fetched into `~/.local/share/ryoku/plugins/<id>/`; turn it on and place it from the Add-ons page. |
| **Nautilus pack** | Right-click actions for Nautilus. | Installed by Ryostore and tracked under `~/.local/share/ryoku/nautilus/`. |

Bundles can declare what they need first: the `multilib` repository (Steam's
32-bit libraries), the CachyOS repository, or the 32-bit GPU drivers for your
hardware. The actuator sets those up before it routes any package.

<Warning>
  **script** items are arbitrary installers, so removing a bundle does **not**
  reverse them; uninstall those tools by hand. Removing **package** items never
  drops anything another installed package still needs. Removing a **plugin**
  deletes its files but keeps your placement in `~/.config/ryoku/plugins.json`,
  so reinstalling drops it back where you had it.
</Warning>

## From a terminal

`ryostore-install` drives everything from a shell. Bundle and item ids are the
ones in the catalogue (for example `gaming`, `developer-essentials`,
`cachyos-layer`).

```bash
# What a bundle has installed and what is missing, as JSON.
ryostore-install status
ryostore-install status bundle gaming

# Install an entire bundle.
ryostore-install install bundle gaming

# Install or remove a single item.
ryostore-install install item gaming steam
ryostore-install remove item gaming steam

# Remove a bundle's package items.
ryostore-install remove bundle gaming
```

Set `RYOSTORE_DRYRUN=1` to print the plan without touching the system:

```bash
RYOSTORE_DRYRUN=1 ryostore-install install bundle gaming
```

The actuator publishes a JSON report per bundle under
`$XDG_RUNTIME_DIR/ryostore/`, which is how Ryostore and the Add-ons page update
in place while a bundle installs or removes.
