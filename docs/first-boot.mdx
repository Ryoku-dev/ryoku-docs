After install, the machine reboots to the Ryoku login screen. Log in with the
user you created; the session starts the window manager you picked in the
installer.

## What happens at the first login

- **The Default rice is applied.** Ryoku ships two rices, Default and NOC.
  Default sets the first look, including its own wallpaper, and the desktop
  recolours from that wallpaper. NOC is one click away in the rice workshop
  (see [Themes](/docs/theming)).
- **The welcome tour opens once.** It walks through the handful of keys that
  open almost everything and lets you pick the interface scale, the bar and the
  desktop widgets, previewed live. It shows on a fresh install, after the
  script installer, and once more when an update reworks it.
- **The Hermes setup opens when you kept Rashin.** If you answered yes to
  Rashin in the installer, a terminal opens once the machine is online and runs
  the Hermes setup: it installs the Hermes agent, connects it and asks you to
  pick a provider. Offline? It waits for a later login. You can run it again
  any time from **Set up Hermes agent** on the **Rashin** page of Ryoku
  Settings, or with `ryoku-rashin setup` in a terminal.

## What you see

- **The frame.** A rounded screen border, the desktop's signature chrome.
  Panels grow out of it instead of floating on top.
- **The bar.** A fresh install shows QS Bar: the launcher, workspaces, the
  clock, the tray and status. Orpheus, Sumi, Kairos, Shima, Python and
  Nomarchy are the other styles, in the welcome tour and Ryoku Settings.
- **The wallpaper** from the Default rice, with the desktop widgets you enable
  painted on it.
- **No windows yet.** Hyprland and niri are tiling window managers, so nothing
  is open until you open it.

`Mod` is `Super` (the Windows or Cmd key on most keyboards).

## Keys worth pressing first

<CardGroup cols={2}>
  <Card title="Open a terminal" icon="terminal">
    `Mod + Return` opens the terminal role, kitty unless you changed it.
  </Card>
  <Card title="Open the launcher" icon="search">
    `Mod + Space` opens the launcher. Type to filter, Enter to launch.
  </Card>
  <Card title="Open Ryoku Settings" icon="sliders" href="/docs/settings">
    `Mod + ,` opens Ryoku Settings, the control center for the whole desktop.
  </Card>
  <Card title="See every shortcut" icon="keyboard" href="/docs/keybindings">
    `Mod + K` opens Kit: every keybind, every Ryoku command, your phone and
    dev tools behind one search field.
  </Card>
</CardGroup>

## If nothing draws

If the bar, the launcher or Ryoku Settings do not appear, switch to a TTY
(`Ctrl + Alt + F2`), log in, then restart the shell and read its log:

```bash
ryoku reload
tail -n 80 ~/.local/state/ryoku-shell.log
ryoku doctor
```
