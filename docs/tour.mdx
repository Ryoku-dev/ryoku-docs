Ryoku's desktop is a window manager plus the Ryoku shell. The window manager
(Hyprland or niri, picked in the installer) composites, handles input and
tiles windows. The Ryoku shell, a Quickshell (QML) frontend driven by the
`ryoku-shell` Go daemon, paints everything else: the frame, the bar, the
launcher, the overview, the capture tool and the desktop widgets. It looks and
works the same on either window manager.

This page is a map of those surfaces. For the keyboard workflow (opening,
focusing, moving and tiling windows) see [Navigation](/docs/navigation); to
configure any of it, see [Settings](/docs/settings).

## Shell surfaces

- **Frame.** The rounded screen border and the popouts that melt into it.
  Always present; it is the desktop's signature chrome.
- **Bar.** **QS Bar**, the default, is a full-width top bar carrying the
  launcher, workspaces, the clock, media, the tray and status. Orpheus, Sumi,
  Kairos, Shima, Python and Nomarchy are the other styles; choose and arrange
  them in Ryoku Settings (Bar Studio). Notifications, the update island and the
  keyring prompt grow from the frame.
- **Launcher.** The command palette (`Mod + Space`): apps, open windows and
  files, plus quick prefixes: `=` calc, `?` web, `/` actions and file search,
  `>` install a package, `@` live radio, and `\` a Rashin ask.
- **Quick settings.** `Mod + Escape` opens the panel with Wi-Fi, power,
  logout, restart and shutdown, media and system graphs.
- **Kit.** `Mod + K` shows the keys that open almost everything.
- **Overview.** The full-screen workspace expo (`Mod + Tab`): scaled
  mini-desktops with live window previews. Click to switch or focus, drag
  windows between workspaces, and step between desktops. The
  [Navigation](/docs/navigation) page covers it in full.
- **Clipboard.** `Mod + V` opens the clipboard history.
- **Capture.** `Mod + Shift + S` opens screenshots and screen recording;
  `Print` takes a screenshot and `Shift + Print` the whole screen. Shots can be
  annotated with rectangles, arrows, pen, marker, blur and text.
- **Visualizer.** `Mod + M` toggles the audio visualizer on the desktop.
- **Desktop widgets.** Clocks, calendars, media and more, painted on the
  wallpaper. Right-click the wallpaper and choose **Edit desktop** to add,
  move and resize them; right-click a widget for its own settings.

The Go daemon (`ryoku-shell`, in `ryoku/shell/ipc/`) is the control plane: it
supervises the persistent components and decides what is on screen, and the QML
frontend renders it. Theme tokens flow from the wallpaper through `matugen`, so
picking a new wallpaper repaints every surface without restarting anything.

## Getting around

Nothing is open when you log in: a tiling window manager only shows what you
launch. Open a terminal with `Mod + Return`, move focus with `Mod + Arrow`, and
switch workspaces with `Mod + 1 … 0`.

[Navigation](/docs/navigation) walks the whole workflow: opening, focusing,
moving, resizing, floating, workspaces, the scratchpad and multi-monitor.
[Keybindings](/docs/keybindings) is the exhaustive bind reference.

## Where things live

| Thing | Hyprland | niri |
| --- | --- | --- |
| Entry point | `~/.config/hypr/hyprland.lua` | `~/.config/niri/config.kdl` |
| Your overrides (loaded last, always win) | `~/.config/hypr/user.lua` | `~/.config/niri/user.kdl` |
| Manual monitor pinning | `~/.config/hypr/monitors_user.lua` | `~/.config/niri/monitors_user.kdl` |
| Generated displays and GPU | `monitors.lua`, `gpu.lua` | `monitors.kdl`, `gpu.kdl` |
| What Ryoku Settings writes | `settings.lua` | `settings.kdl`, `rebinds.kdl` |

Your Ryoku Settings changes are kept in `~/.config/ryoku/user_edits`.
Wallpapers live in `~/Pictures/Wallpapers`, and per-app overrides such as
`~/.config/kitty/user.conf` and `~/.config/fish/user.fish` are left alone by
updates. [Customize](/docs/customize) covers what to put in each layer.

## Logs

```bash
# The shell daemon's log (Arch, CachyOS and Fedora)
journalctl --user -u ryoku-shell -f

# What the window manager reports
ryoku wm status
```

`ryoku-shell` runs as a user service that starts with your session;
`ryoku reload` restarts it.
