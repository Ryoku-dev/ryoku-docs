`Mod` is `Super` (the Windows or Cmd key). Ryoku ships one list of binds for
every window manager, so these work the same on Hyprland and niri. Press
`Mod + K` to open **Kit**, which shows the live list for your machine,
including your own changes.

To swap a chord for your own, use the **Keybinds** page in Ryoku Settings
(`Mod + ,`). It writes `rebinds.lua` on Hyprland or `rebinds.kdl` on niri, so
the shipped chord is simply replaced. Brand-new binds of your own can also go in
`user.lua` or `user.kdl`, which load last and are never touched by updates. See
[Customize](/docs/customize).

| Binding | Action |
| --- | --- |
| `Mod + Space` | App launcher. |
| `Mod + Return` | Terminal. |
| `Mod + Escape` | Quick settings: Wi-Fi, power, logout, restart, shutdown. |
| `Mod + Tab` | Workspace overview: live previews, drag windows between workspaces. |
| `Mod + K` | Kit: the keys and tools at a glance. |
| `Mod + ,` | Ryoku Settings. |
| `Mod + Q` | Close the focused window. |
| `Mod + L` | Lock the screen. |

## Workspaces

A **desktop** is a block of ten workspaces, so every desktop keeps its own
`1..10`. The number keys always mean "of the current desktop" on the screen
you are on.

| Binding | Action |
| --- | --- |
| `Mod + 1 .. 0` | Focus that workspace (the number pad works too). |
| `Mod + Alt + 1 .. 0` | Send the window to that workspace and follow it. |
| `Mod + Shift + 1 .. 0` | Send the window there and stay here. |
| `Mod + Page Up / Page Down` | Previous or next workspace (`Mod + Scroll` too). |
| `Mod + Shift + Page Up / Page Down` | Send the window one workspace up or down. |
| `Mod + Ctrl + Page Up / Page Down` | Swap this workspace with the one above or below. |
| `Mod + H` | Tuck the window into the scratchpad; press again on it to bring it back. |
| `Mod + Alt + H` | Show or hide the scratchpad. |
| `Mod + Tab` | Overview. |
| `Mod + Alt + Tab` | Overview by desktop: step through blocks of ten workspaces. |

## Window manager differences

The list is shared, but a window manager can only honour what it can do. On
Hyprland, which has no column model, `Mod + Home / End`, `Mod + Shift + R`,
`Mod + Ctrl + R`, the workspace swap and `Mod + Shift + Escape` are listed in
Kit as unavailable, with the reason.
