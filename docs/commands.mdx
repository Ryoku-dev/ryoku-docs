Everything Ryoku does from a keybind or a Settings page is also a command, so
anything the desktop can do, a terminal (or a script of yours) can do too. This
page is the map. The commands that matter most on a daily driver come first;
the rest is reference.

## The five that matter

| Command | What it does |
| --- | --- |
| `ryoku update` | Bring Ryoku current, re-lay its config, self-heal, reload. The one maintenance command. |
| `ryoku doctor` | Find and fix stateful drift. Safe to run any time; `--check` changes nothing. |
| `ryoku status` | Channel, version, waiting packages, snapshot count. `--json` for scripts. |
| `ryoku rollback` | List releases and snapshots; `--to <version>` moves back to a release. |
| `ryoku recovery` | Last resort: restore the stable channel and redeploy, whatever state the box is in. |

If something feels wrong, the order is `ryoku doctor`, then `ryoku update`,
then `ryoku rollback`. `recovery` is for a machine that cannot help itself.
Every `ryoku` command is covered in depth on [The ryoku command](/docs/cli).

## `ryoku-shell`, the desktop's remote control

Every surface the shell draws answers to `ryoku-shell <verb>`, which is what
the keybinds call. Useful from a terminal when scripting or diagnosing:

| Command | What it does |
| --- | --- |
| `ryoku-shell launcher` | Toggle the app launcher. |
| `ryoku-shell ask` | Open the Ask bar (`ask chat` and `ask tools` open a mode). |
| `ryoku-shell quicksettings` | Toggle quick settings. |
| `ryoku-shell clipboard` | Open the clipboard history. |
| `ryoku-shell overview` | Toggle the workspace overview. |
| `ryoku-shell lock` | Lock the session (`lock status` reports `locked` or `unlocked`). |
| `ryoku-shell visualizer` | Toggle the desktop audio visualizer (`visualizer-overlay` raises it above windows). |
| `ryoku-shell voice` | Toggle voice typing. |
| `ryoku-shell hub open` | Open Ryoku Settings. |
| `ryoku-shell theme <name>` | Apply a color scheme. |
| `ryoku-shell audio up / down / mute` | Nudge the default output. |
| `ryoku-shell brightness <±n>` | Nudge screen brightness. |
| `ryoku-shell bar ...`, `ryoku-shell dock ...` | Arrange the bar and the dock without touching JSON; see below. |
| `ryoku-shell ping` / `status` | Is the daemon alive, and what does it know. |
| `ryoku-shell reload` | Reload the shell. |

The bar and dock verbs are validated against the same widget catalogue the
settings panels use:

```bash
ryoku-shell bar list
ryoku-shell bar move clock --section right --after media
ryoku-shell bar hide battery
ryoku-shell bar position bottom
ryoku-shell dock pin org.kitty
ryoku-shell dock autohide on
```

## Wallpapers: `ryogami`

| Command | What it does |
| --- | --- |
| `ryogami wallpaper ui` | Open the wallpaper picker. |
| `ryogami wallpaper random` | A random wallpaper with a random transition. |
| `ryogami wallpaper set <path>` | Set a wallpaper, image or video. `--screen <output>` targets one display, `--workspace` the current workspace. |
| `ryogami upscale start <file>` | Upscale an image (`status` and `cancel` follow it). |

## Desktop helpers

The small tools behind keybinds and Settings pages. All on `$PATH`, all fine
to call directly:

| Command | What it does |
| --- | --- |
| `ryoku-app <role>` | Launch your chosen app for a role, such as `terminal`, `browser`, `editor` or `files`. `ryoku-app terminal -- btop` runs a program inside the terminal. |
| `ryoku-monitor` | Display layouts: list, mirror or extend, saved profiles. |
| `ryoku-cmd-record` | Screen recording through GPU Screen Recorder, on the strongest GPU for each monitor. |
| `ryoku-cmd-brightness <±n>` | Backlight and DDC monitor brightness in one command. |
| `ryoku-cmd-caffeine start / stop / toggle` | The Keep Awake inhibitor behind the quick settings tile. |
| `ryoku-cmd-game-mode` | Toggle game mode: no notifications, no idle, panels hidden. |
| `ryoku-cmd-nightlight` | Toggle the night-light temperature shift. |
| `ryoku-cmd-color-picker` | Pick a color from the screen. |
| `ryoku-cmd-ocr` | Grab a region and copy its text. |
| `ryoku-cmd-qr-scan` | Grab a region and decode the QR code in it. |
| `ryoku-cmd-google-lens` | Grab a region and search it with Lens. |
| `ryoku-cmd-calc` | The launcher's inline calculator, standalone. |
| `ryoku-cmd-radio` | The live radio behind the launcher's `@` prefix. |
| `ryoku-cmd-songrec` | Identify the song currently playing. |
| `ryoku-cmd-discord-compress` | Compress a clip until it fits a Discord upload. |
| `ryoku-cmd-folders` | Rebuild the accent-tinted folder icons after a palette change. |
| `ryoku-sysinfo` | The system readout the Hub and Fastfetch share. |
| `ryoku-eq` | The system-wide parametric EQ. |

## Hardware and power

| Command | What it does |
| --- | --- |
| `ryoku-gpu` | GPU report and mode switching on hybrid laptops (`ryoku-gpu-detect` probes, `ryoku-gpu-lib32` adds 32-bit game libraries). |
| `ryoku-clamshell` | The lid-switch daemon: closes to an external display on AC, suspends otherwise. |
| `ryoku-idle` | The idle policy daemon (dim, lock, sleep timings). |
| `ryoku-mic` | Microphone processing (noise suppression) toggle. |
| `ryoku-wifi-powersave` | Wi-Fi power-save toggle for flaky adapters. |

## Where these live

The `ryoku` CLI is Go under `ryoku/cli/`; the shell daemon and its verbs are
`ryoku/shell/ipc/`; Ryogami is `ryoku/shell/ryogami/`; the `ryoku-cmd-*`
helpers are scripts in `ryoku/shell/scripts/`; hardware tools live in
`system/hardware/`. Every one of them ships in the packages, so a script that
works on your machine works on any Ryoku install.
