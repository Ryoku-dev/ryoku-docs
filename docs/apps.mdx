Ryoku ships a curated toolkit, not a grab bag of everything in the
repositories. The installer lets you keep or leave out most of it (see
[Install Ryoku](/docs/install)); whatever you leave out stays out after
updates. Want more software? Ryostore adds whole bundles in one click.

## Core apps

Each core app has a launch key. `Mod` is `Super`. Terminal, editor, browser and
files are **roles**: the key opens whichever app the role points at, and you
can repoint a role in **Ryoku Settings > Keybinds**, where the default apps
live beside the shortcuts.

| App | Role | Key |
| --- | --- | --- |
| Kitty | Terminal | `Mod + Return` |
| Neovim (LazyVim) | Editor | `Mod + N` |
| The browser you picked (Firefox by default) | Browser | `Mod + B` |
| The file manager you picked (Nautilus by default) | Files | `Mod + E` |
| Yazi | Files in the terminal | `Mod + Alt + E` |
| Ryotunes | Music | `Mod + J` |
| Ryoport | VMs, SSH and serial consoles | `Mod + Shift + V` |
| RyoManager | System monitor and task manager | the launcher |

See [Keybindings](/docs/keybindings) for the complete bind list.

## The Ryoku apps

Three of Ryoku's own apps are on by default and listed first in the installer.
Each can be left out there, or removed later; the doctor never puts a removed
app back.

- **Ryotunes** is the music app. The now-playing widgets and the media keys
  follow it like any other player. It updates from its own releases.
- **Ryoport** is the dashboard for virtual machines, SSH hosts and serial
  consoles. It ships inside the desktop package, so leaving it out in the
  installer hides its launcher entry instead of removing files.
- **RyoManager** is the system monitor and task manager: performance graphs
  and the running processes, which you can inspect and end. It reaches
  existing installs once through the doctor.

## The file manager

The installer asks for a file manager:

- **Files (Nautilus)** is recommended: Ryoku's stash actions live in its
  right-click menu.
- **Dolphin**, KDE's file manager.
- **Thunar**, Xfce's light file manager.

The one you pick becomes the files role (`Mod + E` and every "open folder"
action) and the default for folders. Change it later in **Ryoku Settings >
Keybinds**.

## The launcher

Press `Mod + Space` to open the launcher. Start typing to search apps, open
windows, the web and quick math at once, or lead with a prefix to talk to one
provider directly. `F1` inside the launcher shows this list.

| Prefix | What it does |
| --- | --- |
| _(none)_ | Apps, open windows, web results and quick math |
| `/` | Actions: lock, screenshot, media, settings |
| `/file`, `/folder`, `/image`, `/video` | Find files |
| `>` | Packages: `>install`, `>remove`, `>search` |
| `=` | Calculator |
| `?` | Web search, with `!bang` shortcuts |
| `@` | Live radio: `@lofi` tunes in, `@stop` tunes out |
| `\` | One question to the [Rashin](/docs/rashin) agent |

The `\` lane needs Rashin; see [Rashin](/docs/rashin).

## The desktop music player

The desktop **Music player** widget follows whichever MPRIS player is active
(Ryotunes, Spotify, a browser tab or `mpv`), with artwork, transport and a
seekbar.

For Spotify, its backdrop can play the track's **Spotify Canvas**. The Canvas
token is only readable inside the Spotify client, so `ryoku doctor` installs
`spicetify-cli` and wires the bundled `ryoku-canvas` extension for you. The
setup is inert if you do not run Spotify.

## Screenshots

Press `Mod + Shift + S` to open **Ryoshot**, the screenshot and annotation tool.

<Steps>
  <Step title="Capture">
    Choose full screen, a region, or a single window.
  </Step>
  <Step title="Annotate">
    Draw with the rectangle, line, arrow, pen, marker, blur, or text tools, with
    undo and redo.
  </Step>
  <Step title="Save">
    The PNG is written to `~/Pictures/Screenshots`.
  </Step>
</Steps>

## Clipboard, voice, and the visualizer

| Tool | Key | What |
| --- | --- | --- |
| Clipboard history | `Mod + V` | Recent copies (via `cliphist`), pick to paste or delete |
| Voice dictation | `Mod + Grave` | Tap to start Voxtype speech-to-text, tap again to stop |
| Audio visualizer | `Mod + M` | Toggle the desktop audio spectrum (via `cava`) |

Voice dictation types the transcription straight into the focused app. Press
`Mod + Shift + M` to raise the visualizer over your windows instead of leaving
it on the wallpaper.

## Shell and CLI tools

The installer asks for the login shell: Fish (recommended), Zsh with Oh My Zsh,
or Bash with ble.sh, all with the **Starship** prompt. The **Modern CLI tools**
and **Git tools** rows in Apps & tools bring most of these:

| Tool | Replaces / does |
| --- | --- |
| `lazygit` | Full-screen Git TUI |
| `zoxide` | Smarter `cd` that learns your directories |
| `fzf` | Fuzzy finder for files, history, and anything piped in |
| `ripgrep` (`rg`) | Fast recursive search |
| `fd` | Fast, friendly file find |
| `bat` | `cat` with syntax highlighting and paging |
| `eza` | `ls` with colors, icons, and a tree view |
| `btop` | Resource monitor |
| `fastfetch` | System info banner |

## Extra helpers

Smaller tools power specific features, and they are on `PATH` if you want them
directly.

| Tool | Purpose |
| --- | --- |
| `qalc` (libqalculate) | Calculator engine behind the launcher's `=` |
| `songrec` | Recognize the music that is playing |
| `tesseract` | OCR, pull text out of a screenshot |
| `zbar` | Scan a QR code on screen |
| `gpu-screen-recorder` | Screen recording |
| Night light | Warm screen colours, set on **Ryoku Settings > Displays** |

<Tip>
Need software that isn't here? Ryostore installs curated bundles in one click,
and the launcher's package provider (`>install <name>`) installs anything from
the repositories.
</Tip>
