Ryoku has one coherent look, and it takes its color from your wallpaper. Set a
wallpaper and the terminal, the compositor, and the shell all recolor to match,
with no per-app theming and no mismatched palettes. Prefer a fixed palette? Pick
one of the built-in color schemes and lock to it.

## How colors work

Ryoku uses **matugen** to read your current wallpaper, extract a palette from
it, and write that palette into every surface at once.

| Target | Generated file |
| --- | --- |
| Kitty (terminal) | `~/.config/kitty/current-theme.conf` |
| Hyprland (compositor) | `~/.cache/ryoku/hypr-colors.lua` |
| Qt apps | `~/.config/qt6ct/colors/ryoku.conf` |
| btop and Fastfetch | `~/.config/btop/themes/ryoku.theme`, `~/.config/fastfetch/ryoku-colors.json` |
| The shell (bar, launcher, widgets) | `~/.cache/ryoku/colors.json` |

That palette has three behaviours, set in the wallpaper picker (`Mod + W`,
then `Shift + S` for its settings) under **Theme > Palette behaviour**:

- **Follow wallpaper** (default): colors regenerate from each new wallpaper.
  Change the wallpaper, change the whole system's colors.
- **Fixed palette**: colors come from the scheme picked under **Palette >
  Theme** and stay put whatever wallpaper you set.
- **Keep current colours**: nothing changes until you switch back.

<Tip>
Only the *accent* follows the wallpaper. The brand vermillion, the red-sun
motif, and the 力 mark stay fixed on every wallpaper, so a sun is always a sun.
</Tip>

## Color schemes

With **Fixed palette** on, **Palette > Theme** lists the built-in schemes:
Catppuccin Mocha, Dracula, Everforest Dark Medium, Gruvbox Dark Medium,
Kanagawa Wave, Nord Dark, One Dark, Rosé Pine, Solarized Dark and Tokyo Night.

Schemes installed from Ryostore join the list, and so do palettes you save in
the **Theme designer**, which edits each interface color on a color wheel with
a live preview. **Custom seeds** builds a full palette from a few hex colors of
your own. **App themes**, on the same tab, recolors supported desktop apps
from the palette as well.

## Switching a scheme

<Steps>
  <Step title="Open the picker's settings">
    Press `Mod + W` for the wallpaper picker, then `Shift + S`, and open the
    **Theme** tab.
  </Step>
  <Step title="Lock the palette">
    Set **Palette behaviour** to **Fixed palette**.
  </Step>
  <Step title="Pick a scheme">
    Choose one under **Palette > Theme** and the desktop recolors to it. Set
    **Palette behaviour** back to **Follow wallpaper** to let the wallpaper
    drive the colors again.
  </Step>
</Steps>

## Wallpapers and Ryogami

Ryogami is the wallpaper picker and daemon. Wallpapers live in
`~/Pictures/Wallpapers`, and a shipped set is installed for you.

| Key | Action |
| --- | --- |
| `Mod + W` | Open the wallpaper picker |
| `Mod + Shift + W` | Random wallpaper, with an animated transition |
| `Ctrl + D` in the picker | The download browser: Wallhaven, Steam Workshop, Unsplash, Pexels and more |

- **Picker styles.** Slices, depth, hex, wall, sandy, hand, collection and
  duel. A fresh profile opens a wide slices picker with the Ash flip and a
  gentle wobble, at 1.2x scale; small screens get smaller slices.
- **Targets.** A wallpaper can go on every display, one display or one
  workspace (**All**, **This monitor**, **This workspace**).
- **Image optimisation.** New PNG, JPEG and GIF wallpapers are re-encoded to
  WebP when they arrive, with the quality preset. The original goes to
  Ryogami's trash for a few days. Turn it off under **Settings > Library >
  Images & recovery > Auto-optimise new images**.

With **Follow wallpaper** on, every wallpaper change recolors the whole
desktop.

## Rices

A rice is a saved look: the wallpaper, the shell and bar settings, the
compositor look, the widgets, the Fastfetch style and the palette. Rices live
in the wallpaper picker's **Rices** tab.

- **Default and NOC ship with Ryoku**, each with its wallpaper and preview. A
  fresh install applies Default at the first login and keeps its wallpaper.
- **Save your own.** Saving captures the current wallpaper and a preview. If
  Ryogami has optimised the wallpaper since you set it, the saved rice picks up
  the WebP copy.
- **Apply, export and import.** Applying a rice snapshots your current setup
  first, so going back is one click. Rices export to a file you can share and
  import on another machine.

## The fixed brand

matugen moves the accent, but a few things never move. These are the brand
constants, independent of any wallpaper or theme.

| Constant | Value |
| --- | --- |
| Vermillion accent (the red sun) | `#e2342a` |
| Kintsugi gold | `#d9a441` |
| Brand mark | 力 (the kanji seal) |

Fonts are fixed too: **Fraunces** for display headlines, **Space Grotesk** for
UI, **JetBrains Mono Nerd Font** for code and labels, and **Noto** as the
fallback (including CJK). The cursor is **Bibata**.
